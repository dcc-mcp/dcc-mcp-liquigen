# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include credentials, license data, private projects, exported assets,
machine-specific paths, process identifiers, or unredacted diagnostic bundles
in a public issue.

The adapter binds automation to an exact LiquiGen process and window. Reports
about process binding, project path containment, native command dispatch, or
artifact validation should include the smallest redacted reproduction and the
adapter/LiquiGen versions involved.

This project is an unofficial integration and does not redistribute LiquiGen
software or presets. Vulnerabilities in LiquiGen itself should be reported to
JangaFX through its official support channel.
